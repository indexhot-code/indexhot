What we measure on each surface

Each platform page reports the same three outcomes, because the same question matters on all six: was the brand named, was a source of ours attached, and did anything we said survive into the answer.

On ChatGPT we report the mention-to-citation ratio, which is unusually wide because many answers carry no sources at all. On Perplexity we report citation rate alongside absorption, because that surface attaches many sources and compresses each of them.

Gemini and AI Overviews are measured in two layers: eligibility in ordinary search results, then use in the generated surface. A page that fails the first layer cannot pass the second, and reporting them as one number is how teams end up rewriting content that was never in the pool.

All four pages use the same fifty-prompt library, so a comparison across surfaces reflects platform behaviour rather than four different question sets.

Why these four and not others

We cover the surfaces that account for the large majority of generative answer consumption, and we would rather measure four well than twenty badly.

Copilot, Claude, Grok and the various regional assistants are real surfaces with real share. Including them would roughly double the manual workload for a measurement whose variance is already the main constraint. When the library can be run cheaply at that scale, they get pages.

The inclusion test we apply is simple: does the surface retrieve and cite, or does it answer from memory only? A surface that never attributes a source can still name brands, but it cannot be measured for citation and absorption, which are the outcomes this standard exists to score.
