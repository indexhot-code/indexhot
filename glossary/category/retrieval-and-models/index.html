Retrieval and models

How a system finds your page, cuts it up and decides which part to use. This group explains why a good page can be absent from an answer, and why the fix is almost never 'write more'.

Retrieval is mechanical: expand the query, fetch candidates, chunk them, re-rank, then fit what is left into a budget. Each stage has a corresponding content property, and applying the wrong one is why teams rewrite pages that were never the problem.

Start with query fan-out and chunking if you want the two facts that change how pages are written. Start with grounding if you want to understand why answers sometimes describe your product incorrectly.

Retrieval-Augmented Generation retrieving external documents before generating an answer Grounding anchoring generated output to verifiable external sources Hallucination confidently stated output with no basis in the sources Query Fan-Out splitting one query into several sub-queries searched in parallel Semantic Search retrieval by meaning rather than exact keyword match Vector Embeddings numeric representations of text used for similarity matching Chunking splitting documents into passages for retrieval and embedding Re-ranking a second pass that re-scores retrieved passages for relevance Hybrid Search combining keyword matching and vector similarity in one retrieval pass Context Window the maximum amount of text a model can consider at once Semantic Gap The distance between the words a page uses and the meaning a query expresses. Retrieval Window The recency and scope limits within which a retrieval system will accept sources. Multi-turn Context The accumulated conversation state that shapes how a later question is interpreted and answered. Model Version Drift Changes in answers caused by a model or index update rather than by anything on your site.

Frequently asked questions

Do I need to understand embeddings to do this work?

No. You need to know that both exact wording and meaning are matched, which is enough to write for both.

Which term explains most citation failures?

Chunking. Passages that lose their subject when cut are unusable regardless of how good the page is.
