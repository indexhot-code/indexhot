Core concepts

The eight surfaces and practices that define the category. Read this first if you are new, because every other group assumes these distinctions: an answer engine, generative search, zero-click search and an AI overview are related but not interchangeable.

Most misunderstandings in this field come from conflating the surface with the technique. Optimisation for a ranked result list and optimisation for a synthesised answer share tools but not success criteria.

The terms here are the ones a team needs in order to brief work, argue about scope and write a statement of what is being measured.

Generative Engine Optimization the practice of making a brand visible, citable and quotable inside AI-generated answers Answer Engine Optimization optimising content to be chosen as the direct answer, not just a ranked result AI Search Visibility how often, how prominently and how deeply a brand appears in AI answers Answer Engine a search system that returns a direct answer instead of a list of links Generative Search search that synthesises a new answer from retrieved sources Zero-Click Search queries resolved on the results or answer surface without a visit Google AI Overviews the AI-generated summary block at the top of Google results AI Snippet a short machine-generated passage lifted from sources to answer a query Answer Format The shape an AI answer takes: prose, a ranked list, a comparison table or a set of steps. Query Refinement The follow-up questions a user asks after an initial AI answer, and the second retrieval they trigger. Competitor Set The specific brands an AI answer names as alternatives for a given query.

Frequently asked questions

Which terms should I learn first?

Generative engine optimization, AI search visibility and answer engine. The rest refine those three.

Do these terms appear in Google's documentation?

Some do not. Several are used in practice and defined here so they can be applied consistently.
