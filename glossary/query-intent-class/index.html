What is Query Intent Class?

Last updated November 2026 · Reviewed against the IndexHot GEO Measurement Standard v1.0

Query intent class is a grouping of questions by what the asker is trying to do, not by topic. In answer surfaces the class decides which content shape can win: a definition, a comparison table, a recommendation or a transaction path.

In short: Grouping questions by what the asker wants, which decides the page shape that can answer them.

The four classes that matter here

  • Definitional. What is X. Answered by a short direct definition with a boundary.
  • Comparative. X versus Y. Answered by a dated table with attributes and a loser column.
  • Recommendational. What should I use for Z. Answered by named options with conditions.
  • Transactional. How much, how fast, how to start. Answered by prices, lead times and a next step.

A page can serve two classes if it is structured for both, and almost never serves four. Most underperforming pages attempt all four in a single narrative, which produces a document that matches no class well.

Why class beats topic in planning

Topic planning produces one page per subject. Class planning produces one page per question shape, which is how buyers actually move: they define, then compare, then ask for a recommendation, then check the transaction terms. A brand weak in the comparative class loses the middle of the purchase even when its definitional pages are excellent.

This is also why a prompt library should be classified before it is written. Ten definitional prompts and no comparative ones produces a report that flatters a page set incapable of winning the comparison stage.

Class and absorption

Recommendational questions absorb framing; definitional ones absorb a sentence; transactional ones absorb a number. Expecting a definitional page to produce recommendation-level absorption is the most common misreading of an absorption report.

A diagnostic use

Classify every prompt in your library and count per class. A library with no comparative prompts while competitors lead every comparison is not a visibility problem; it is a coverage problem, and it is fixable in a week.

Frequently asked questions

Is intent classification the same as SEO intent?

Largely, with one addition: answer surfaces add a recommendation class that classic search folds into informational queries.

How many prompts per class?

Enough to see the shape: five to ten per class per locale, with the comparative ones carrying named competitors.

Can one page serve two classes?

Yes if each class gets its own section with a self-contained opening sentence. Four is a warning sign.
