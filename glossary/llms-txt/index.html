What is llms.txt?

Last updated November 2026 · Reviewed against the IndexHot GEO Measurement Standard v1.0

llms.txt is a proposed convention for placing a plain-text file at a site's root that summarises its purpose and links key content, intended to help language models understand and navigate the site.

In short: A proposed file that summarises a site for language models.

Why it matters

It aims to solve the problem of models guessing which pages matter. Uptake is uneven and it is not an official standard, so it should be treated as a cheap supplement to crawlability and structured data, not a substitute.

How to work with it

Publish a concise markdown-style summary with a short description and curated links to your most important pages, and keep it current.

Common mistakes

  • Assuming llms.txt is officially supported and prioritising it over fundamentals.
  • Dumping the entire site structure instead of curating what matters.
  • Publishing it once and letting links rot.

Real example

A documentation site published llms.txt listing 40 curated pages. Crawl logs showed two AI user-agents requesting it, and no measurable change in citation rates over one quarter. The effort was small, the return was close to zero.

How to measure it

Check server logs for requests to the file. If no crawler fetches it, the file is doing nothing regardless of how well it is written.

Where it breaks

Treating llms.txt as a ranking lever is a category error. It is an unendorsed proposal, and crawlability plus entity clarity remain the actual determinants.

How it differs from adjacent terms

Crawlability is access; llms.txt is a curated summary that assumes access already works. Compared with Indexability, which determines whether pages can be stored, llms.txt influences nothing structural and is not an endorsed specification. Treating it as a substitute for crawl and index fundamentals inverts the priority order.

Quick checklist

  • Server logs checked for actual requests to the file.
  • Curation limited to genuinely important pages.
  • Links verified and kept current.
  • Fundamentals handled first: robots, status codes, internal links.
  • Claims about its effect kept proportional to evidence.

FAQ

Does llms.txt improve AI visibility?

There is no reliable public evidence that it does at scale. It costs little to publish, but crawlability, content structure and entity clarity remain the decisive factors.

Is llms.txt a Google standard?

No. It is a community proposal, not an official specification from Google or any major model provider.
