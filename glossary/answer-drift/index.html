What is Answer Drift?

Last updated November 2026 · Reviewed against the IndexHot GEO Measurement Standard v1.0

Answer drift is the change in an AI answer to the same fixed prompt across runs, weeks or model versions. It is caused by sampling, index updates, model updates and context differences, and it is the main reason a single check cannot be reported as a result.

In short: The tendency of an identical prompt to return a materially different answer over time, without any change on your side.

Why it matters

Every number in GEO is a sample from a moving system. If you do not know how much your answers drift on their own, you cannot tell your work from the noise, and every report becomes a claim you cannot defend.

Drift also has a diagnostic use. Prompts that drift heavily are usually prompts where the underlying sources disagree or where the model has no strong prior, which is often where a well-structured page can actually win a slot.

How to work with it

Measure drift before you measure yourself: run the same prompt set three times within one hour, then again a week later, and code the differences.

  • Same-session variance tells you sampling noise. Changes across a week tell you index freshness. Changes across a model release tell you version drift.
  • Record a stability flag per prompt: stable, unsettled or volatile. Only stable prompts belong in a headline trend.
  • Do not "fix" drift by averaging runs from different model versions into one number; version changes reset the baseline.

Common mistakes

  • Reporting a single run as a result, then explaining a two-point movement that was sampling noise.
  • Changing the prompt wording slightly between cycles, which conflates drift with your own edits.
  • Treating drift as purely bad. Unstable answers are where the source set is unsettled and influence is still available.

FAQ

Is answer drift the same as hallucination?

No. Hallucination is an unsupported claim. Drift is change over time in an answer that may be entirely correct on each occasion.

How many runs settle a prompt?

Three runs in one session give a working estimate. A prompt that returns three different brand sets is unsettled regardless of how many more runs you add.
