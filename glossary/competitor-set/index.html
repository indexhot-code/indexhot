What is Competitor Set?

Last updated November 2026 · Reviewed against the IndexHot GEO Measurement Standard v1.0

The competitor set is the group of brands a system treats as the relevant options for a prompt. It is not your marketing list of competitors; it is the model's, and the two often diverge in ways that matter.

In short: The specific brands an AI answer names as alternatives for a given query.

Why it matters

You cannot be recommended in a set you are not in. Before any absorption work, the first question is whether the answer's option space includes the brand at all, and whether the set is stable or shifting.

The divergence between your list and the model's is itself informative. Brands you consider irrelevant may be the ones the model treats as the category, which means the category definition it holds is not yours.

How to work with it

Code the named brands per prompt, then aggregate the set across the cluster.

  • Track set membership and set order separately; entering the set and moving within it are different achievements.
  • Compare your list to the model's list and note the differences explicitly.
  • Watch set churn month to month; a stable set means entrenched incumbents, a churning one means an open field.

Common mistakes

  • Assuming a query's competitor set matches the category you sell into.
  • Tracking only your own presence, which hides whether the set itself is being reshaped.
  • Treating a single answer's list as the set; union across three runs is closer to reality.

FAQ

How large are competitor sets typically?

For most commercial categories, three to six brands are named across a prompt set, with two or three recurring in nearly every answer.

Can a brand enter a set without being named anywhere?

Rarely. Entry usually requires third-party corroboration, not only an owned page.
