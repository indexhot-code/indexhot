What is Soft 404?

Last updated November 2026 · Reviewed against the IndexHot GEO Measurement Standard v1.0

A soft 404 is a missing page served with a success status. The URL is gone, the server says it is fine, and the body is an apology or a redirect-shaped landing page. It is one of the most common technical defects on otherwise well-built sites.

In short: A response that says 200 OK while delivering a page that does not exist, teaching crawlers to distrust your URL inventory.

Why it happens

Single-page applications route unknown paths to the app shell. Frameworks render a not-found component without setting the status. CMS platforms serve a friendly page by default. In each case the intent is good and the signal is wrong.

What it costs

  • Mass near-duplicate content: every unknown URL looks like a page with the same body.
  • Deletions that never take effect, so retired pages keep competing with their replacements.
  • Crawl budget spent on URLs that do not exist.
  • A citation landing on a URL that returns an apology, which is worse than no citation.

The check

  1. Request a path that certainly does not exist, such as a random slug under a real directory.
  2. Confirm the status is 404 or 410, not 200.
  3. Confirm the body is a real not-found page with navigation, not the home page.
  4. Repeat for one path per content type, since each template fails differently.

Fixing it without breaking people

Return the correct status and keep the helpful page. A 404 with navigation and a search box is fine for users and correct for machines. What must go is the 200.

For pages that moved, use a single 301 to the new URL rather than a 200 landing page. For pages intentionally retired, 410 is defensible and clearer than 404.

Frequently asked questions

Is a custom 404 page a soft 404?

No, if it returns 404. The defect is the status, not the design.

Do redirects create soft 404s?

Only when they point to a generic page with a 200. That is a soft 404 with extra steps.

Does this affect AI answers specifically?

It affects any retrieval system, and it matters more where citations are shown, because a cited dead URL is visible to the reader.
