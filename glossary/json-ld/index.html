What is JSON-LD?

JSON-LD is a JSON-based format for expressing linked data, and the recommended way to embed Schema.org structured data in a web page inside a script block.

In short: A JSON format for embedding structured data in web pages.

Why it matters

It is the least invasive and most reliable way to publish structured data: it lives in one block, does not interfere with markup, and is parsed consistently by major crawlers and AI systems.

How to work with it

Place one script block of type application/ld+json in the head, keep it valid JSON, and mirror every value in visible content.

Common mistakes

  • Producing invalid JSON that silently fails parsing.
  • Duplicating the same entity with conflicting values across blocks.
  • Using JSON-LD to claim facts the page does not support.

FAQ

Is JSON-LD better than microdata?

Generally yes for maintainability. It is easier to generate, test and keep consistent, and it is the format Google documents most clearly.

How do I validate JSON-LD?

Parse it as JSON first, then run it through a structured-data validator. Broken JSON is the most common failure and is invisible to readers.
