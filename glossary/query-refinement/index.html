What is Query Refinement?

Last updated November 2026 · Reviewed against the IndexHot GEO Measurement Standard v1.0

Query refinement is the sequence of narrowing questions that follows a first answer. Unlike a search box where refinement is a new search, in a chat surface the follow-up reuses the earlier context, so the second answer is shaped by both the original question and the answer just given.

In short: The follow-up questions a user asks after an initial AI answer, and the second retrieval they trigger.

Why it matters

Most commercial decisions happen on the second and third turn, not the first. A brand cited in the opening answer is far more likely to be discussed in the follow-up; a brand absent from the opening answer rarely appears later.

Refinement also explains why the first answer matters disproportionately: it sets the entity set the conversation will operate on, and later turns mostly elaborate within it.

How to work with it

Build a small refinement tree per cluster and run the common second turns as separate prompts.

  • Typical second turns: pricing detail, implementation effort, a direct comparison between two named options, and a risk or switching question.
  • Run the follow-ups as standalone prompts to see whether you appear when the conversation has narrowed.
  • Score entry at turn one separately from persistence at turn two; they fail differently.

Common mistakes

  • Measuring only first-turn answers, which captures awareness and misses the decision turns.
  • Assuming a follow-up prompt is equivalent to a fresh search; context carry-over changes the retrieval.
  • Ignoring that an answer's entity set constrains later turns, so absence early is expensive later.

FAQ

Do follow-up answers cite the same sources?

Often a subset, sometimes new ones. Refinement tends to narrow sources rather than expand them, which makes early presence valuable.

How do I test refinement at scale?

Two turns per prompt is enough for a working read: run the base prompt, then the most common next question, and score them separately.
