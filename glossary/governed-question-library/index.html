What is Governed Question Library?

Last updated November 2026 · Reviewed against the IndexHot GEO Measurement Standard v1.0

A governed question library is a fixed, versioned set of prompts, with documented selection rules and change control, used consistently across platforms and measurement cycles.

In short: A fixed, versioned set of prompts used for every measurement run.

Why it matters

Without governance, measurement becomes anecdote. If prompts change between runs, differences in scores reflect the prompts rather than the brand. Governance is what makes a GEO number reproducible and therefore actionable.

How to work with it

Freeze the list, record the version, document why each prompt exists, and change it only on a scheduled revision with the old results retained.

Common mistakes

  • Adding prompts mid-cycle to chase a good result.
  • Letting each stakeholder contribute prompts with no inclusion criteria.
  • Losing the mapping between a prompt and its historical results.

Real example

A team changed its prompt list every month to reflect new product messaging. Scores rose steadily and meant nothing, because each run measured a different question set. Freezing the library exposed a real flat trend underneath.

How to measure it

Version the library, store every historical run against that version, and record the reasoning for each change at the moment you make it.

Where it breaks

A frozen library can encode old assumptions. Review it on a schedule, and when you change it, re-baseline rather than splicing new results onto old ones.

How it differs from adjacent terms

A Branded Prompt and a Non-Branded Prompt are element types; the library is the governed container that fixes their mix and history. Compared with Mention Rate, the library is infrastructure rather than a metric: without it, every metric becomes an anecdote. Governance is what makes a decrease credible enough to act on.

Quick checklist

  • Selection rule written before prompts are added.
  • Version number recorded with every run.
  • Historical results retained per version, never overwritten.
  • Changes made on a schedule, not mid-cycle.
  • Every prompt traceable to a real buyer question.

FAQ

What makes a question library governed?

A written selection rule, a stable version number, documented change history and the same list applied to every platform and every run.

How often should the library change?

Rarely. A quarterly or semi-annual revision is usually enough. Change it deliberately, and re-baseline rather than pretending the trend is continuous.
