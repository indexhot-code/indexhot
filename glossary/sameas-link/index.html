What is sameAs Link?

Last updated November 2026 · Reviewed against the IndexHot GEO Measurement Standard v1.0

sameAs is a property in JSON-LD that points from an entity to an external page representing the same thing, typically a Wikipedia entry, a LinkedIn or Crunchbase profile, or another owned domain. It is the standard way to state identity across the web.

In short: A schema property that declares a URL as an authoritative identifier for the same entity.

Why it matters

It gives a model a resolvable handle. Instead of inferring that five differently-worded descriptions refer to one company, it can follow the link and conclude they do.

It matters most for brands without a knowledge panel. A brand with a Wikipedia entity rarely needs the help; a brand without one needs every corroborating declaration it can get.

How to work with it

Add sameAs URLs to the Organization node, pointing only at pages that clearly describe the same entity.

  • Include the profiles a model would plausibly trust: Wikipedia, Wikidata, LinkedIn company page, Crunchbase, GitHub organisation.
  • Avoid pointing at pages that describe a different entity with a similar name; a wrong sameAs makes ambiguity worse.
  • Keep the list short and accurate; forty links to press mentions add noise rather than identity.

Common mistakes

  • Using sameAs to link press coverage, which describes the entity rather than being an identifier for it.
  • Adding a sameAs to a disambiguation page or a directory listing that aggregates several companies.
  • Declaring the property on pages that have no Organization node, so the declaration has nothing to attach to.

FAQ

Does sameAs improve AI answers directly?

Not directly. It improves entity resolution, which shows up as fewer wrong descriptions and more consistent naming.

Is sameAs required?

No, but for brands with ambiguous names it is the cheapest single fix available.
