What is Baseline Freeze?

Last updated November 2026 · Reviewed against the IndexHot GEO Measurement Standard v1.0

A baseline freeze is the decision to stop changing the measurement setup for a defined period. It is the least glamorous step in GEO and the one that decides whether any later number means anything.

In short: Locking a prompt set, its version and its run conditions so later measurements are comparable.

What gets frozen

  • The prompt list itself, including exact wording and grouping.
  • The surfaces measured, and whether AI Overviews is counted separately.
  • Run conditions: locale, account state, time of day band, number of runs.
  • The coding rules, including the absorption rubric and who applies it.

What a freeze is not

It is not a promise that nothing will change. Providers ship new models, and a model change forces a re-baseline whether you want one or not. The freeze covers what you control; the version annotation covers what you do not.

It is also not a permanent commitment. Most teams freeze for a quarter, measure, then deliberately revise and re-baseline with the change documented.

Why teams skip it and what it costs

Freezing feels like bureaucracy when the first report is due next week. The cost arrives two quarters later, when a number moves and nobody can say whether the prompts, the model or the work caused it. At that point the measurement programme is unfalsifiable and therefore political.

A minimal implementation

  1. Store the library in one file with a version number and a date.
  2. Record the exact run conditions in the same file.
  3. Log every edit with a reason; never edit silently.
  4. Publish the version alongside any number you show externally.

Frequently asked questions

Does a freeze prevent improving the library?

No. It schedules improvement, which is different from forbidding it.

What happens after a model release?

You re-baseline and annotate. The freeze is over the setup you control, not over the provider's behaviour.

Is a written baseline enough?

Only if it includes run conditions. A prompt list without locale and account state is not reproducible.
