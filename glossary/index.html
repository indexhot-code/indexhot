The IndexHot GEO Glossary

100 terms used in AI search visibility work, each defined in one sentence and explained in context. Written for teams who need to measure and improve brand presence in generated answers.

Core concepts (13)

What GEO is and the surfaces it targets.

Generative Engine Optimization the practice of making a brand visible, citable and quotable inside AI-generated answers Answer Engine Optimization optimising content to be chosen as the direct answer, not just a ranked result AI Search Visibility how often, how prominently and how deeply a brand appears in AI answers Answer Engine a search system that returns a direct answer instead of a list of links Generative Search search that synthesises a new answer from retrieved sources Zero-Click Search queries resolved on the results or answer surface without a visit Google AI Overviews the AI-generated summary block at the top of Google results AI Snippet a short machine-generated passage lifted from sources to answer a query Answer Format The shape an AI answer takes: prose, a ranked list, a comparison table or a set of steps. Query Refinement The follow-up questions a user asks after an initial AI answer, and the second retrieval they trigger. Competitor Set The specific brands an AI answer names as alternatives for a given query. GEO Audit A structured review of why a site is absent from AI answers, run in stage order rather than content order. Zero-Mention Prompt A prompt where the brand appears nowhere in the answer, not even as a passing name.

Retrieval and models (18)

How systems find and ground on your content.

Retrieval-Augmented Generation retrieving external documents before generating an answer Grounding anchoring generated output to verifiable external sources Hallucination confidently stated output with no basis in the sources Query Fan-Out splitting one query into several sub-queries searched in parallel Semantic Search retrieval by meaning rather than exact keyword match Vector Embeddings numeric representations of text used for similarity matching Chunking splitting documents into passages for retrieval and embedding Re-ranking a second pass that re-scores retrieved passages for relevance Hybrid Search combining keyword matching and vector similarity in one retrieval pass Context Window the maximum amount of text a model can consider at once Semantic Gap The distance between the words a page uses and the meaning a query expresses. Retrieval Window The recency and scope limits within which a retrieval system will accept sources. Multi-turn Context The accumulated conversation state that shapes how a later question is interpreted and answered. Model Version Drift Changes in answers caused by a model or index update rather than by anything on your site. Passage Retrieval finding the section of a page, not the page, that answers part of a query Snippet Selection choosing which sentences of retrieved material reach the answer Query Intent Class grouping questions by what the asker wants, which decides the page shape Contextual Chunking splitting a document so each chunk keeps the heading and context it needs

Measurement (31)

The metrics that make visibility reproducible.

Mention Rate the share of tracked prompts in which your brand is named Citation Rate the share of prompts in which your domain is linked as a source Absorption Rate the share of prompts where your specific claims enter the answer Citation Absorption how deeply a cited source's content is reused in the answer Share of Voice your brand's share of mentions within a tracked prompt set Citation attribution of a domain as a source inside an AI answer Branded Prompt a question that includes the brand name explicitly Non-Branded Prompt a category question asked without naming any brand Governed Question Library a fixed, versioned set of prompts used for every measurement run AI Visibility Index a ranked index of brands scored on the same AI prompt set Citation Gap the difference between being mentioned and being cited as a source Answer Sentiment the tone an AI answer uses when it discusses your brand Long-Tail Prompt a specific, constrained question with clear intent and low volume Citation Source Diversity how spread out the sources behind an AI answer are Answer Drift The tendency of an identical prompt to return a materially different answer over time, without any change on your side. Visibility Gap The difference between how visible a brand is on branded prompts and how visible it is on non-branded ones. Prompt Cluster A group of prompts that share one buyer intent, scored together because they fail for the same reason. Share of Answer How much of an answer's text and structure is occupied by one brand relative to the others named. Brand Recall Whether a model names a brand without being prompted by its name, from memory rather than retrieval. Source Concentration How few domains account for most citations in a category's answers. Visibility Dashboard An interface that reports AI visibility metrics over time, usually as a composite score with trends. Prompt Volume An estimate of how often a given prompt or cluster is asked, used to weight a prompt library. Citation Velocity The rate at which a domain gains or loses citations across a prompt set between two measurement cycles. Answer Coverage The share of a category's prompt set in which the brand appears at all, regardless of depth. Competitor Benchmark A same-run comparison of the brand against named competitors, using an identical prompt library. Prompt Drift the slow change in how people phrase questions, which dates a fixed library Baseline Freeze locking a prompt set and its run conditions so later numbers compare Reporting Cadence how often to measure, set against noise rather than the calendar Prompt Coverage how much of the buying path a library samples, not how many prompts it has Absorption Lift absorption change for one edited page, measured against a control Citation Decay citations a page used to earn, lost to staleness or displacement

Entity and content (18)

How machines identify and interpret your brand.

Entity Clarity how unambiguously a model can identify your brand as a distinct entity Knowledge Graph a structured network of entities and their relationships Schema Markup structured data vocabulary embedded in pages to describe entities JSON-LD a JSON format for embedding structured data in web pages llms.txt a proposed file that summarises a site for language models Topical Authority depth and consistency of coverage across a topic Brand Entity your brand as a machine-resolvable object with attributes and relations Organization Schema structured markup that declares your organisation as an entity FAQ Schema markup that pairs questions with answers for machine extraction Entity Ambiguity The state in which a model cannot tell two entities with the same or similar names apart. sameAs Link A schema property that declares a URL as an authoritative identifier for the same entity. Author Authority Whether the person credited on a page is a verifiable entity with relevant expertise. E-E-A-T Experience, expertise, authoritativeness and trust — the quality framework used to judge whether content is credible. Entity Home The single page a brand designates as the authoritative description of itself. Entity Consistency one name, description and category everywhere a machine looks Provenance Signal evidence of where a claim came from, which makes it safe to repeat Entity Resolution deciding whether several names and domains are one organisation Claim Verifiability whether someone outside the company could check the claim

Technical foundations (20)

Crawl, index and extractability prerequisites.

Content Extractability how easily a machine can isolate, quote and reuse your content Crawlability whether crawlers can discover and fetch your pages Indexability whether a page is eligible to be stored in a search index Canonical Tag a signal declaring the preferred URL for a piece of content Internal Linking links between your own pages that distribute authority and signal structure AI Referral Traffic visits that arrive from an AI answer or assistant Competitive Citation Share your share of cited sources versus competitors in a prompt set AI Crawler a bot that fetches content for model training or live retrieval Content Freshness how current a page is, and how clearly it says so Crawl Budget The amount of crawling a site can expect, and how efficiently that allowance is spent. Render Blocking Content that only appears after JavaScript runs, and is therefore invisible to some crawlers and fetchers. Status Code Hygiene Whether the site returns the correct HTTP status for every kind of URL: 200, 301, 404 or 410. Content Decay The gradual loss of citation and traffic as a page's facts age or as better-structured competitors appear. Crawl Log The record of which URLs a crawler requested and what each returned. Render Parity whether the HTML a bot fetches matches the page a visitor sees Soft 404 a missing page served with a 200, teaching crawlers to distrust your URLs Content Gating logins, forms and paywalls that remove text from retrieval Retrieval Latency the time budget a pipeline allows a page before moving on Crawl Trap near-infinite generated URLs that consume crawl capacity HTML-First content present in the first response, before any script runs
