AI Answer Teardown Tool

Paste any AI answer and the tool scores it the way we code answers manually: named, cited, substantive, structured. It reports which check failed and what that failure usually means.

0 out of 100, weighted for answer-level visibility

Runs entirely in your browser. Nothing is uploaded, and no answer text is stored.

What the four checks mean

The tool scores an answer against the same four things we code manually: whether the brand is named, whether your domain is among the sources, whether the answer contains repeatable substance, and whether it is structured so a passage can be lifted without losing its meaning.

  • Named (30). A case-insensitive scan of the answer text. Naming is necessary and never sufficient.
  • Cited (30). Domain extraction from the answer plus any source list pasted with it. This is the check most people skip, because a mention feels like a win.
  • Substance (25). Numbers, units and dates. An answer built from your page usually carries some of them; a competitor's vague page contributes none.
  • Structure (15). Words per sentence and whether the answer has parts. Long unbroken sentences are the typical reason a correct claim still fails to survive summarisation.

Weights are deliberate and arguable. Substance outranks structure because a well-formed sentence with nothing in it is still nothing; if you weight differently, change the numbers in the page rather than the reasoning.

How to read the output

A score under 25 is not a content problem. It is an access or identity problem, and rewriting copy will not move it. Check crawl access, then check that the page states plainly what the product is and who it is for.

Between 25 and 55, the brand is appearing incidentally. Something on the page is readable enough to describe you and not specific enough to be used as evidence. That is usually where the fix belongs.

The failure mode at the top of the range is subtler: a high score on a single answer that does not repeat on the next run. One good answer is an anecdote. Run the same prompt five times before treating it as a position.

What this tool cannot tell you

It reads one answer, once. It cannot tell you how often that answer appears, whether it is stable across runs, or whether the same prompt at a different time produces a different brand. All three matter, and all three need repeated runs rather than a single paste.

It also cannot see answers you never pasted, and it cannot distinguish a citation in passing from a citation that supplied the argument. That distinction is what absorption coding exists for, and it needs a human read.

Frequently asked questions

Is this the same as your manual coding?

The same four dimensions, scored mechanically. Manual coding adds absorption level, which requires judging whether the answer adopts your framing or merely lists you.

Why does a citation score separately from a mention?

Because the two fail independently and need different fixes. A brand can be described accurately and never used as the source, which means the evidence sits elsewhere.

Can I paste an AI Overview?

Yes. Paste the overview text and any links shown with it. Overviews cite sparsely, so a missing citation there is less informative than on a surface with a source list.
