Prompt Library Generator

Build a fifty-prompt baseline: ten branded prompts and forty non-branded, grouped by intent.

The split matters. Branded prompts test what the model already believes about you; non-branded prompts test whether it would ever introduce you. A library that only asks about your own name measures recognition, not acquisition. The forty non-branded prompts below follow the eight intent clusters we use in every published run.

Why these eight clusters

They follow the order a buyer actually moves through: awareness, comparison, budget, implementation, trouble, switching, risk, and fit. Each cluster fails differently, which is why they stay separate rather than being averaged into one number.

  • Category and comparison decide whether you exist in the consideration set at all.
  • Pricing and implementation are where technical documentation beats marketing pages, and where most brands are absent.
  • Trouble and switching capture buyers already in motion, the group with the shortest path to a decision.
  • Risk and fit turn a mention into a shortlist position, because they carry the reassurance a buyer needs.

How to use it once generated

Freeze the list before the first run and version it. Rewording a prompt between cycles is the fastest way to produce a trend line that describes your edits rather than the market.

Run every prompt three times per surface and code the median answer, recording the date and model version beside each row. Record mention, citation and absorption in three separate columns: they fail for different reasons, and a single pass or fail hides which one applies.

Frequently Asked Questions

Why ten branded and forty non-branded?

Branded prompts are a cheap sanity check: if a model cannot describe you correctly when asked directly, nothing else is measurable. The other forty carry the actual signal, because they test whether the model would surface you for a question you did not write.

Can I use my own prompts instead?

Yes, and you should add prompts drawn from real sales calls and support tickets. The value of this tool is the shape and the ratio, not the exact wording. What matters is that the final list is frozen and dated.

Is fifty enough for reliable conclusions?

Enough for trend decisions at cluster level, not enough for a confident single-cluster claim. If one cluster holds five prompts, treat a change of one prompt as noise until it repeats across two cycles.
