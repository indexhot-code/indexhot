How to Buy GEO Work: Direct Answers

8 questions · answered directly

Buying AI visibility work is harder than buying SEO because the deliverable is usually a number rather than a position. These eight answers are about the artefacts that make a number checkable: a frozen prompt library, dated runs, a stated citation definition and a written absorption rubric.

Should I run a pilot before committing to a vendor?

Yes, and scope it as a measurement rather than a trial. A pilot should produce a baseline you would keep regardless of the vendor decision: fifty prompts, three runs, a coding sheet, and the arithmetic shown. If the vendor's pilot output cannot be recalculated by someone else, you have been shown a result rather than given a method.

What should an RFP for AI visibility work ask?

Ask for artefacts, not capabilities. The prompt library, the platforms and dates of each run, the definition of a citation, the absorption rubric, the coding procedure, and how a score is computed from the raw answers. Add one question that filters most submissions: what would make this number wrong, and how would you detect it.

How do I get internal approval for GEO spend?

Frame it against a decision that already has a budget, usually content production or paid search. The argument that travels is not visibility for its own sake but that pages already being commissioned are not written in a form that answers can use. Absence in answers is a defect in output you already pay for, which is a cheaper conversation than a new line item.

What KPIs belong in a GEO contract?

Mention rate, citation rate and absorption rate, measured separately per surface, plus a prompt library both parties sign off and freeze. Never accept a single composite score as the deliverable: it hides which of the three moved, and it cannot be checked. A share-of-voice figure against named competitors is defensible only if the competitor set came from the same run.

How long should a pilot run before I judge it?

Ninety days, with a read at thirty. Structural work shows in mention and citation within weeks; absorption moves slower, and recall barely moves at all in a quarter. Judging at two weeks measures sampling noise, and judging at two weeks is the most common way a workable programme gets cancelled.

How do I compare two vendors quoting different scopes?

Convert both to cost per prompt per surface per month, then compare what each includes as artefact. A cheaper quote that reports a single score is not cheaper, it is less measurement. The comparison that matters is whether both would produce the same number on the same day, and only a stated library and rubric makes that testable.

What happens to my data if I switch vendors?

Ask before signing: who owns the prompt library, the raw answers and the coding sheet, and in what format they leave. The defensible answer is that all three are yours and exportable as plain files. A vendor that treats the prompt library as intellectual property is selling lock-in, and a re-baseline on exit wipes the history that made the work defensible.

How do I budget for GEO when there is no comparable line item?

Budget against the content spend you already have, not as a new category. Most programmes cost less than one additional article per month in tooling, plus the editing time to restructure existing pages. The expensive part is not measurement; it is rewriting pages that were never written to be extracted, which is a content budget line either way.
